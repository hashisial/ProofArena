# Module Creation Contract

1. Create only a module explicitly approved by the scaffolding gate.
2. Check exact and similar paths before creation.
3. Never move, rename, copy, or re-export existing files during scaffolding.
4. Never wire routes, navigation, layouts, APIs, auth, roles, backend registries, or dashboards.
5. Never add business logic, services, controllers, models, adapters, mocks, or placeholder behavior.
6. Never create module API clients, routers, auth providers, role systems, config, or deployment files.
7. Initial approved content is limited to `README.md`; a barrel is allowed only after a proven local pattern and explicit approval.
8. README must state purpose, ownership, allowed/forbidden contents, platform/shared dependencies, migration prerequisites, and no behavior added.
9. Existing platform/shared systems remain outside target modules.
10. Stop and report a blocker if approval, ownership, or duplicate-path evidence is incomplete.
