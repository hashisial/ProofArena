## Audit Result

- Existing shared surfaces approved with caution: `client/src/components/ui/` and `client/src/services/shared/`.
- Whole-folder approval denied: root hooks, utilities, types, constants, server utilities/constants/services, and `components/common`.
- Platform-owned exclusions: routing, navigation, auth/session, API client, dashboard/layout, config/env, database, error/response contracts, design tokens, and documentation governance.
- New runtime shared libraries authorized: none.
